# SnapSharp v1.0.9 发版说明

## 缺陷修复

- **置顶贴图遮挡对话框**：修复从置顶贴图打开 OCR 后，OCR 服务器配置被压在底层、无法操作的问题；统一处理设置、保存、颜色选择、画布扩展、文字输入及确认框等窗口的所属关系，打开模态对话框时临时解除遮挡窗口的置顶状态，关闭后恢复。
- **截图形状和比例无法选择**：元素捕获模式下也可选择矩形、椭圆、自由套索、多边形及适用的宽高比；选择形状或比例后自动切换到区域截图，避免只有捕获模式可操作。
- **独立尺子移动后读数不正确**：尺子改为以自身左上角为零点，移动后继续显示相对距离；缩放尺寸和末端读数按实际屏幕像素计算，不再混用桌面绝对坐标。
- **截图辅助界面中文乱码**：修复尺子、十字线及像素操作提示中的中文显示问题，补齐新增功能的全部语言包翻译。

## 功能改进

- **GitHub 在线更新**：在“设置 → 关于”中检查正式版更新、查看发版说明并下载 Windows x64 更新包；安装前校验 SHA256、压缩包结构和程序版本，退出后替换程序并重启，替换失败时回滚，保留模型、设置和历史数据。
- **像素级截图取景**：改进放大镜与像素网格，显示坐标及选区尺寸；选区建立前可用方向键移动取景点，建立后可逐像素移动选区，Shift + 方向键调整尺寸。支持不同显示缩放比例及屏幕边缘限制，键盘微调不受吸附干扰。
- **尺子和十字线工具**：截图工具条增加尺子和“十”形十字线按钮，使用固定快捷键 R、X 切换，快捷键说明显示在上方提示区域；首次默认关闭，记住每个工具的开关状态，并在多显示器截图窗口间同步。方向键提示仅在当前可以移动时显示。
- **独立屏幕尺子**：托盘菜单新增“屏幕尺子”，可独立打开、拖动和调整大小，显示相对坐标与像素尺寸，方便测量屏幕元素的距离和大小。
- **回归检查与本地化维护**：新增真实窗口层级、嵌套对话框、多显示器状态同步、100%／150%／200% 缩放下的像素操作和尺子读数检查；验证新增提示在 21 个语言／地区资源包及默认英文中的完整性，并检查中文界面渲染。

# SnapSharp v1.0.9 Release Notes

## Bug Fixes

- **Pinned images covering dialogs**: fix OCR server settings appearing behind a pinned image and becoming inaccessible. Handle dialog ownership consistently for settings, saving, color selection, canvas expansion, text input and confirmations. Temporarily clear obstructing windows' topmost state while a modal dialog is open and restore it afterward.
- **Unavailable capture shapes and aspect ratios**: allow shape and applicable aspect-ratio selection from element capture mode. Choosing a rectangle, ellipse, freehand lasso, polygon or aspect ratio switches to region capture automatically.
- **Incorrect readings after moving the desktop ruler**: measure from the ruler's own top-left origin. Moving it preserves relative distances, while resizing and endpoint readings use physical screen pixels instead of absolute desktop coordinates.
- **Corrupted Chinese capture-guide text**: repair Chinese ruler, crosshair and precision-control labels, and translate the new features across all language packs.

## Improvements

- **GitHub in-app updates**: check for stable releases, read release notes and download Windows x64 updates from Settings → About. Verify SHA256, archive structure and executable version before installation. Replace the application after exit, restart it and roll back if replacement fails, while preserving models, settings and history.
- **Pixel-level capture controls**: improve the magnifier and pixel grid, with coordinates and selection dimensions. Use arrow keys to move the sampling point before selecting or move the selection afterward; use Shift + arrow keys to resize it. Account for display scaling and screen boundaries, and bypass snapping during keyboard adjustments.
- **Ruler and crosshair tools**: add ruler and plus-shaped crosshair buttons to the capture toolbar. Toggle them with fixed R and X shortcuts, shown in the top hint area. Both start disabled, remember their individual states and synchronize across capture windows on multiple monitors. Show arrow-key hints only when movement is available.
- **Standalone screen ruler**: open a draggable, resizable ruler from the tray menu. Read relative coordinates and pixel dimensions to measure distances and element sizes on screen.
- **Regression checks and localization maintenance**: add checks for native window order, nested dialogs, multi-monitor preference synchronization, pixel controls at 100%/150%/200% scaling and ruler readings. Validate new labels in all 21 language/region packs plus default English, including rendered Chinese capture interfaces.
