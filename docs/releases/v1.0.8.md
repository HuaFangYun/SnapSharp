# SnapSharp 发版说明

## 缺陷修复

- **翻译覆盖识别原文**：识别原文与译文分别保留，翻译失败或取消时仍可继续使用原文；修改原文或目标语言后清除旧译文，避免显示不匹配的结果。
- **多行翻译难以对照**：本地翻译和在线 API 按非空行逐行处理，保留原文空行，并将单行译文中的换行合并，方便逐行核对。
- **无法清空截图快捷键**：区域、全屏和当前窗口截图快捷键现在与贴图快捷键一样可以留空禁用，保留非空快捷键的格式及重复检查。
- **解决方案平台不匹配**：解决方案和主程序统一使用 x64，避免使用默认平台构建时与原生依赖的架构不一致。

## 功能改进

- **更多界面语言**：在原有中英文基础上补充捷克语、德语、西班牙语、法语、意大利语、日语、韩语、波兰语、葡萄牙语、俄语、土耳其语及繁体中文，并提供部分地区版本；随程序分发 21 个语言／地区资源包及默认英文。新增译文为机器翻译初稿，部分地区版本复用同语种译文，仍需母语审校。
- **翻译结果视图**：识别窗口可选择目标语言，并在“原文”“译文”“原文 + 译文”之间切换；双语视图逐行交替显示，复制和导出使用当前视图的文本，原文仍可编辑。
- **PP-OCRv6 模型选择**：下载配置升级为 Tiny、Small、Medium 三档，默认 Small；CPU 显示 Tiny／Small，DirectML 显示 Small／Medium。模型和字典分别按固定版本、大小及 SHA256 校验，支持断点续传和复用已有有效安装；已有手动配置的模型路径继续保留。
- **抠图设备独立配置**：抠图可单独选择 CPU 或 DirectML，不再必须共用 OCR 的执行设备；设置页和识别窗口按设备筛选模型，CPU 提供轻量模型，DirectML 提供包括完整版及高质量透明抠图在内的模型选择。设备筛选不代表所有显卡上的高质量模型均已通过稳定性验收。
- **Qwen3.5 本地翻译模型**：新增 2B、4B、9B、27B Q4_K_M 和 27B Q5_K_M，按可用内存或显存筛选，优先选择可用的 4B；继续兼容原有 Qwen2.5 1.5B 模型，并将 llama.cpp 下载运行库更新为 b12470。不同大小模型仍需在目标设备上验证效果和性能。
- **本地翻译与在线 API 分区**：设置页分开显示本地模型和在线服务，通过单选项切换；单独记住 API 服务商，本地模式禁用在线授权和 API 配置控件。
- **设置布局更紧凑**：调整设置页留白、控件和底栏尺寸，快捷键名称与输入框同行显示；使用非 PaddleOCR 引擎时禁用不适用的 ONNX 下载及设备控件。
- **语言包维护与验证**：新增语言包生成脚本、术语覆盖文件及离线校验脚本，检查资源键、格式参数、模板字段和文件筛选器；扩展本地化自检，覆盖全部语言包、语言选择、窗口标题及设置页离屏渲染，并同步更新本地化、模型配置和架构说明。

# SnapSharp Release Notes

## Bug Fixes

- **Translation replacing recognized text**: keep source text and translations separately. Failed or canceled translation preserves the source; editing the source or changing the target language clears stale translations.
- **Difficult multiline comparison**: local translation and online APIs translate nonempty lines individually, preserve blank source lines and flatten line breaks within each translated line for easier comparison.
- **Capture shortcuts could not be cleared**: region, full-screen and active-window shortcuts can now be left empty to disable them, just like pin shortcuts. Nonempty shortcuts retain format and duplicate checks.
- **Solution platform mismatch**: use x64 consistently for the solution and application to match native dependencies when building with the default platform.

## Improvements

- **More interface languages**: add Czech, German, Spanish, French, Italian, Japanese, Korean, Polish, Portuguese, Russian, Turkish and Traditional Chinese, including selected regional variants. The application ships 21 language/region resource packs plus default English. New translations are machine-generated drafts; some regional variants reuse their base-language translations and still need native-speaker review.
- **Translation result views**: choose a target language in the recognition window and switch between source, translation and bilingual views. The bilingual view alternates source and translated lines. Copy and export use the current view, while the source remains editable.
- **PP-OCRv6 model selection**: offer Tiny, Small and Medium downloads, with Small as the default. CPU offers Tiny/Small; DirectML offers Small/Medium. Models and dictionaries use pinned revisions, sizes and SHA256 checks, resumable downloads and reuse of valid installations. Existing manually configured model paths are retained.
- **Independent background-removal device**: choose CPU or DirectML separately from OCR. Settings and recognition windows filter models by device: CPU offers lightweight models, while DirectML also offers full-size and high-quality transparency models. Device filtering does not establish stability of high-quality models on every GPU.
- **Qwen3.5 local translation models**: add 2B, 4B, 9B and 27B Q4_K_M, plus 27B Q5_K_M. Filter choices by available RAM or VRAM and prefer 4B when eligible. Existing Qwen2.5 1.5B models remain supported, and the downloadable llama.cpp runtime is updated to b12470. Model quality and performance still require validation on the target device.
- **Separate local translation and online API settings**: display local models and online services in separate sections with a mode selector. Remember the API provider separately and disable online consent and API configuration controls in local mode.
- **More compact settings**: refine spacing, controls and footer sizing, and place shortcut labels beside their inputs. Disable inapplicable ONNX download and device controls when a non-PaddleOCR engine is selected.
- **Language-pack maintenance and validation**: add generation scripts, terminology overrides and an offline validator for resource keys, format parameters, template fields and file-dialog masks. Expand localization self-tests to cover all packs, language selection, window titles and offscreen settings rendering, and update localization, model configuration and architecture documentation.
