# SnapSharp v1.1.1

## 更新内容

- 修复混合 DPI 显示器间截图、标尺与窗口定位的物理坐标换算问题。
- 改进竖向长截图的采样、向上回滚及拼接，避免重复追加已采集内容。匹配不确定时保留原始帧并打开接缝修正，支持手动位移、撤销重做及工程保存。长截图入口统一为竖向。
- 增加已下载模型的存储管理与安全清理。
- 将 ONNX 推理移至独立工作进程，补充异常恢复和诊断，降低原生推理失败对主程序的影响。
- 改进放大镜与取点准星的黑白像素对比。
- 增加录屏长测、设备拔插检查入口和硬编失败后软件重试验证；实际平均帧率偏离目标 ±5% 时提示。

## 运行与已知限制

- Windows x64 自包含压缩包：解压完整目录后运行 `SnapSharp.exe`，无需另装 .NET Desktop Runtime。原生功能可能仍需 VC++ x64 运行库；Windows N 版录屏需要媒体功能组件。模型权重需另行下载。
- 录屏 60fps、长时间音画同步、设备拔插、Windows N 干净系统及播放器矩阵尚未全面验收；性能提示不代表目标帧率保证。
- 竖向长截图的 Electron、Office 和浏览器动态页面兼容矩阵仍需实机验证。固定栏可裁除，无法可靠匹配时请修正接缝或减慢滚动重新采集。横向滚动不承诺支持。
- 真实大型模型与各品牌 GPU 的兼容性仍取决于模型、显存和驱动。

## English

- Fix physical-coordinate conversion across displays with different DPI settings.
- Improve vertical scrolling capture, reverse scrolling and stitching without duplicating revisited content. Preserve uncertain frames for manual seam correction, undo/redo and project saving. Capture entry points now use vertical scrolling only.
- Add downloaded-model storage management and safe cleanup.
- Isolate ONNX inference in a worker process and improve failure recovery and diagnostics.
- Improve black-and-white pixel contrast in magnifier reticles.
- Add recording soak/hotplug checks and hardware-to-software retry verification; warn when observed average FPS falls outside ±5% of the target.

Extract the complete Windows x64 package and run `SnapSharp.exe`. The .NET runtime is included; native features may still require the VC++ x64 runtime and Windows media components. Model weights are downloaded separately. Recording device/synchronization/performance matrices, clean Windows N systems, dynamic desktop scrolling applications and large-model GPU compatibility remain subject to further real-device testing. Horizontal scrolling is outside the supported scope.
