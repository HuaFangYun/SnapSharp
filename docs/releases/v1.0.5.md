# SnapSharp 发版说明

## 缺陷修复

- **感谢反馈**：[吾爱破解 Terri（UID: 2167331）](https://www.52pojie.cn/?2167331)。
- **录屏设置未完整记忆**：补存系统声音、麦克风开关及设备选择；录制结束后不再清空勾选；记住保存目录，不再每次弹框。
- **设置窗口被遮挡**：配置期间隐藏区域边框与悬浮工具条；录屏配置窗口不再被排除捕获。
- **系统声音设备未跟随系统默认输出**：改为查询 Windows 当前默认播放设备，而非默认选列表第一项。
- **Qwen 下载反馈不足及失败重下**：增加连接阶段提示、独立进度条与失败弹窗；明确区分成功／失败／取消；支持自动重试与断点续传；错误写入日志。
- **窗口选区包含标题栏**：优先截取窗口内画面，滚轮可按需调整范围。
- **箭头标注无法连续添加**：单击后可连续添加；文本与气泡添加后进入编辑状态。

## 功能改进

- **录屏设置与文件管理**：记住上次选项；新增独立录屏目录，按时间自动命名；支持“另存为”。
- **系统声音设备选择**：默认“跟随系统默认输出”，每次录制重新获取；手动指定时记住选择。
- **统一元素选区（桌面／浏览器）**：桌面端基于窗口句柄 + UI Automation 识别控件；浏览器端无需安装扩展，通过系统辅助功能接口识别页面元素，已验证 Chrome 网页按钮与输入框。截图默认进入“元素”模式；悬停自动吸附并显示边框、类型与尺寸，单击锁定进入标注，滚轮切换层级，识别失败回退到窗口或手动选区。“元素”加入 `Tab` 模式循环。暂不支持 CSS 选择器和视口外完整元素截图。

# SnapSharp Release Notes

## Bug Fixes

- **Thanks for the feedback**: [Terri (UID: 2167331) on 52pojie.cn](https://www.52pojie.cn/?2167331).
- **Recording settings not fully remembered**: now save system audio, microphone toggles, and device selection; no longer clear checkboxes after recording; remember the output directory instead of prompting each time.
- **Settings window obscured**: hide the region border and floating toolbar during configuration; the recording config window is no longer excluded from capture.
- **System audio device not following system default output**: query the current Windows default playback device instead of defaulting to the first item.
- **Insufficient Qwen download feedback and re-download on failure**: add connection-stage status, a dedicated progress bar and failure dialog; clearly distinguish success / failure / cancellation; support automatic retry and resume; persist errors to logs.
- **Window selection including title bar**: prioritize capturing window content, with the mouse wheel to adjust the range.
- **Arrow annotations cannot be added continuously**: click to add repeatedly; text and bubble annotations enter editing state after being added.

## Improvements

- **Recording settings and file management**: remember last options; add a dedicated recording directory with time-based naming; support "Save As".
- **System audio device selection**: default to "Follow System Default Output", re-queried each recording; remember manual selections.
- **Unified element selection (desktop / browser)**: desktop uses window handles + UI Automation; browser elements are detected through the system accessibility interface without installing extensions, verified with Chrome page buttons and inputs. Captures start in Element mode by default. Hover auto-snaps and shows the border, type, and size; click to lock and annotate; the mouse wheel switches hierarchy levels; fall back to window or manual selection on failure. "Element" is added to the `Tab` mode cycle. CSS selectors and full offscreen element screenshots are not yet supported.
