# NimCap 截图工具 v1.1.4

- 中文界面使用「NimCap 截图工具」，英文为「NimCap Screenshot」。截图工具栏与贴图菜单统一使用「图像工具」，其中可切换文字识别、抠图和去水印等功能。
- 托盘统一用「贴图」打开剪贴板图片。对已有图片，先贴图，再右键打开「图像工具」。已配置的剪贴板识别快捷键仍可使用。
- 水印检测未找到可修复区域时，提示切换到涂抹模式手动标记水印。
- 模型许可证诊断日志无法写入时，应用可继续启动。启动过程中出现无法恢复的错误时，应用退出并释放单实例占用。
- 更新检查和下载使用 `nimcap/nimcap-screenshot` 的 GitHub Releases。

从 SnapSharp v1.1.3 或更早版本迁移时，请手动下载 `nimcap-screenshot-v1.1.4-win-x64.zip`，解压完整压缩包并运行 `NimCap.Screenshot.exe`。此后可使用新版的在线更新。压缩包包含 .NET 运行时，模型、个人设置和历史记录保留在各自的数据目录。校验值见 `SHA256SUMS.txt`。

## English

- The app is named **NimCap Screenshot** in English. **Image Tools** is available from the capture toolbar and the pin context menu, with modes for text recognition, background removal, watermark removal, and more.
- To process a clipboard image, choose **Pins** in the tray, then open **Image Tools** from the pin's context menu. Existing recognition shortcuts still work.
- If automatic watermark detection finds no pixels to repair, the app explains how to mark the watermark with the brush.
- The app can start when it cannot write the model license diagnostic log. If startup fails, the process exits and releases its single-instance lock.
- Update checks and downloads use GitHub Releases in `nimcap/nimcap-screenshot`.

To migrate from SnapSharp v1.1.3 or earlier, download `nimcap-screenshot-v1.1.4-win-x64.zip`, extract the full archive, and launch `NimCap.Screenshot.exe`. Future updates can use the in-app updater. The package includes the .NET runtime. Models, settings, and history stay in their data folders. Verify the archive against `SHA256SUMS.txt`.
