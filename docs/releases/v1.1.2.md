# SnapSharp v1.1.2

## 更新内容

- 增加证件自动分类与结构化识别，支持身份证人像面、国徽面及正反面合图，以及驾驶证、行驶证、户口本、护照、银行卡和营业执照。
- 证件结果统一为可编辑文本，支持自动换行、复制和 TXT 导出；合并多行字段时去除空白。
- 增加图片左转、右转、旋转 180° 和上下翻转。识别预览支持鼠标滚轮缩放、拖动平移、双击适应窗口。
- 截图工具栏与置顶编辑工具栏增加一键脱敏，使用高斯模糊处理敏感词，支持撤销、重做及复制、保存输出。
- 脱敏支持手机号、身份证号、银行卡号、邮箱、车牌号、姓名字段及地址；配置本地 Qwen 模型与运行库后，可补充分析无标签的人名和地址。
- 修正脱敏范围：按命中的词语定位，保留字段标题及周围正文；保留 OCR 字符、词语位置并通过独立推理进程传递。

## Windows x64

下载 `SnapSharp-v1.1.2-win-x64.zip`，解压完整目录后运行 `SnapSharp.exe`。压缩包包含 .NET 运行时；模型权重需在应用中另行下载。`SHA256SUMS.txt` 提供安装包校验值。

## English

- Add automatic document classification and extraction for ID cards (front, back or combined), driving and vehicle licenses, household registers, passports, bank cards and business licenses.
- Present document results as editable, wrapping text with copy and TXT export. Join multiline field values without whitespace.
- Add image rotation and vertical flipping, plus wheel zoom, drag pan and double-click fit in recognition previews.
- Add one-click Gaussian-blur redaction to screenshot and pinned-image editing, with undo/redo and copy/save support.
- Detect phone, ID and bank-card numbers, email addresses, license plates, labeled names and addresses. A configured local Qwen model can additionally identify unlabeled names and addresses.
- Restrict redaction to matched text spans, preserving labels and surrounding prose. Preserve OCR character/word positions across the isolated inference worker.

Extract the complete Windows x64 package and run `SnapSharp.exe`. The .NET runtime is included; model weights are downloaded separately. Package checksums are provided in `SHA256SUMS.txt`.
