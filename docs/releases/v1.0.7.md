# SnapSharp 发版说明

## 缺陷修复

- **感谢反馈**：[吾爱破解 netdna518（UID: 2223913）](https://www.52pojie.cn/?2223913)。
- **重复下载同一模型**：OCR、抠图、表格、公式及 Tesseract 字库下载前先校验已有文件，通过后直接复用，兼容旧版本的随机名称目录；切换下载源或多次点击不会再重复下载有效模型。
- **字库切换产生重复副本**：中英双语字库可直接用于单一语言；添加语言时在原目录补齐缺失文件，本地导入也会复用已有字库，安装失败保留原有文件。
- **移动程序后模型路径失效**：exe 所在文件夹及其子目录内的模型、字典和本地翻译运行库自动保存为相对路径，外部目录保留绝对路径；数据目录迁移时同步更新。

## 功能改进

- **官方源与中国源**：在“OCR 与识别”“一键抠图”和“翻译”页选择模型下载源；中国源使用清华 PyPI、HF-Mirror 和第三方 GitHub 加速，保留文件校验和本地翻译断点续传。
- **下载配置更清晰**：移除“常规”页重复的下载源选择，名称统一为“中国源 / China source”，中英文界面和说明同步更新。
- **便携使用更方便**：旧版绝对路径配置仍可读取，保存一次设置后自动转换；退出程序后，将程序、设置和模型所在文件夹一起移动即可继续使用其中的模型。
- **已有模型无需重新下载**：优先复用最近的有效模型目录，缺失、损坏或版本不符的文件不会被复用；已有旧副本不会自动删除。

# SnapSharp Release Notes

## Bug Fixes

- **Thanks for the feedback**: [netdna518 (UID: 2223913) on 52pojie.cn](https://www.52pojie.cn/?2223913).
- **Repeated model downloads**: OCR, background-removal, table, formula and Tesseract downloads verify and reuse existing files, including legacy installation folders. Switching sources or clicking repeatedly no longer downloads another copy of a valid model.
- **Duplicate language data after switching languages**: bilingual Tesseract data can serve either language. Adding a language installs only missing data in the existing folder. Local imports also reuse installed data, and failed additions preserve existing files.
- **Broken model paths after moving the application**: models, dictionaries and local translation runtimes inside the executable folder are stored as relative paths. External paths stay absolute, and data-folder migration updates references.

## Improvements

- **Official source and China source**: choose a model download source on the **OCR & Recognition**, **Background Removal** and **Translation** pages. The China source uses Tsinghua PyPI, HF-Mirror and a third-party GitHub proxy, retaining file verification and resumable local translation downloads.
- **Clearer download settings**: remove the redundant source selector from General settings and consistently label the option **China source** in English and **中国源** in Chinese. Interface hints and documentation have been updated.
- **Easier portable use**: existing absolute paths remain readable and are converted when settings are saved. Exit the application, then move the executable, settings and model folders together to continue using the models kept in that folder.
- **Reuse existing models**: prefer the most recent valid installation. Missing, corrupt or different-version files are not reused, and old duplicate folders are not deleted automatically.
