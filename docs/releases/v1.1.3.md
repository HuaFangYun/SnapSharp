# SnapSharp v1.1.3

## 更新内容

- 统一图片识别各标签页的操作布局：顶部固定模型、设备、设置；图片下方固定模式、参数、开始／停止、撤销、复制／保存／贴图。不可用操作置灰，窄窗口优先收起辅助参数。
- 新增去水印与图像修复，支持 MI-GAN 快速档、LaMa 默认档和 Moebius 精细候选档，以及 SLBR 水印检测。模型均可在软件内选择官方源或中国源下载安装、校验和配置，无需安装 Python 或手动转换模型；Moebius 耗时较长，效果需结合图片评估。
- 缺少模型时留在当前页面，展示模型用途、大小和下载源，确认后自动下载并使用，可随时取消。
- 托盘操作统一支持快捷键配置，并可逐项选择是否显示在托盘菜单中；设置和退出固定保留。
- 合并贴图入口：自动识别剪贴板图片、文字或颜色值，复制色彩值后可直接新建颜色贴图。
- 修复屏幕取词，支持本地 Paddle OCR 与已安装的 Windows OCR 回退，改善超时、错误提示和多显示器定位。
- 每次启动仅自动检查一次新版，使用期间不定时检查；设置页保留手动检查，移除内嵌发版说明。
- 修复截图异步捕获、WGC 恢复和滚动长截图后端，补充多语言资源、第三方模型声明及使用文档。

## Windows x64

下载 `SnapSharp-v1.1.3-win-x64.zip`，解压完整目录后运行 `SnapSharp.exe`。压缩包包含 .NET 运行时，不包含模型、个人设置和历史记录；所需模型可在软件内另行下载。`SHA256SUMS.txt` 提供压缩包校验值。

## English

- Add watermark removal and image repair with MI-GAN, LaMa, Moebius (detail candidate) and SLBR detection. Download, verify and configure models in the app through official or China sources, without Python or manual conversion. Moebius is slower and results depend on the image.
- Keep missing-model prompts on the current page, showing purpose, size and download sources before installation.
- Configure shortcuts and tray visibility for tray actions; Settings and Exit always remain available.
- Use one clipboard pin action for images, text and recognized color values.
- Repair screen text recognition with local Paddle OCR or installed Windows OCR fallback, clearer errors and improved multi-monitor placement.
- Check for updates once at startup; retain manual checks and remove inline release notes.
- Fix asynchronous capture, WGC recovery and scrolling capture backends; update translations, model notices and documentation.

Extract the complete Windows x64 package and run `SnapSharp.exe`. The .NET runtime is included. Models, personal settings and history are excluded. Download models separately in the app. Verify the package with `SHA256SUMS.txt`.
