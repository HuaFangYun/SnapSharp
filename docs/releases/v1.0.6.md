# SnapSharp 发版说明

## 缺陷修复

- **感谢反馈**：[吾爱破解 netdna518（UID: 2223913）](https://www.52pojie.cn/?2223913)。
- **部分模型下载目录未统一**：OCR、抠图模型和 Tesseract 字库下载统一跟随当前数据目录，不再固定保存到旧目录。
- **更改目录后模型或历史记录路径失效**：迁移时同步更新设置中的模型路径和历史索引，保留外部文件引用。
- **迁移异常导致数据丢失的风险**：目标已有应用数据时拒绝覆盖；复制和配置提交成功后才删除原数据，迁移失败保留并继续使用原目录。

## 功能改进

- **默认保存在 exe 同目录**：新安装的设置、已下载模型和历史记录默认保存在 `SnapSharp.exe` 所在目录。
- **支持修改数据目录**：在“设置 → 常规 → 本地数据”浏览或输入新目录，也可一键选择“使用 exe 所在目录”。
- **已有数据迁移提示**：保存目录修改时提示迁移已下载模型、设置和历史记录；从托盘退出后重新启动，执行迁移并切换到新目录。
- **兼容旧版本数据**：旧版本已有数据继续使用原目录，可通过设置手动迁移；程序文件和无关文件保留在原位置。

# SnapSharp Release Notes

## Bug Fixes

- **Thanks for the feedback**: [netdna518 (UID: 2223913) on 52pojie.cn](https://www.52pojie.cn/?2223913).
- **Inconsistent model download locations**: OCR models, background-removal models, and Tesseract language data now follow the active data folder instead of always using the old location.
- **Broken model or history paths after changing folders**: migration updates model paths in settings and history indexes while preserving references to external files.
- **Data-loss risk when migration fails**: existing application data in the destination is never overwritten. Original data is removed only after copying and committing the new location succeed; failed migrations preserve and continue using the original folder.

## Improvements

- **Executable-folder default**: new installations store settings, downloaded models, and history beside `SnapSharp.exe`.
- **Configurable data folder**: browse or enter a new location in **Settings → General → Local Data**, or click **Use executable folder**.
- **Migration confirmation for existing data**: saving a folder change prompts you to migrate downloaded models, settings, and history. Exit SnapSharp from the tray and launch it again to migrate and activate the new folder.
- **Existing-installation compatibility**: existing data stays in its original folder until you choose to migrate it in Settings. Application files and unrelated files remain in place.
