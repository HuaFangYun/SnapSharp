# NimCap 截图工具 v1.1.5

- 图像工具为文字识别、内容总结、条码和公式提供独立的结果面板。切换工具会保留各自的结果和编辑内容；旋转或更换图片后，会清除旧结果，避免误用。
- 内容总结同时展示识别出的原文和可编辑的总结结果，便于对照检查。复制、导出和撤销操作使用当前工具的结果，处理期间禁用编辑和输出操作。
- 改进截图 OCR 的复制体验和本地内容总结，并补充识别工具的操作提示及多语言资源。
- 更新中英文使用指南、离线 AI 模型选择说明和项目迁移说明，补充功能示例，并将现有配图按比例缩小至最大宽度 600px。
- 完善 GitHub 自动构建与发布：检查版本号、运行更新器及混合 DPI 回归检查，生成 Windows x64 自包含压缩包和 SHA-256 校验文件。

下载 `nimcap-screenshot-v1.1.5-win-x64.zip` 后，请解压完整压缩包并运行 `NimCap.Screenshot.exe`。压缩包包含 .NET 运行时，无需单独安装；离线 AI 模型需要另行下载或导入。校验值见 `SHA256SUMS.txt`。

从 SnapSharp v1.1.3 或更早版本迁移时，请手动下载并解压新版。使用 NimCap v1.1.4 的用户也可通过程序内更新入口获取此版本。

## English

- Image Tools now provides separate result panels for OCR, summaries, barcodes, and formulas. Switching tools preserves each tool's results and edits; rotating or replacing the image clears stale results.
- Summaries display the recognized source alongside editable output. Copy, export, and undo target the active tool; editing and output actions are disabled while processing.
- Improved screenshot OCR copying and local content summaries, with additional tool hints and localized resources.
- Updated the Chinese and English guides, offline AI model selection advice, migration notes, and feature examples. Existing illustrations now have a maximum width of 600px with their aspect ratios preserved.
- Improved automated GitHub builds and releases with version validation, updater and mixed-DPI regression checks, a self-contained Windows x64 archive, and SHA-256 checksums.

Download `nimcap-screenshot-v1.1.5-win-x64.zip`, extract the full archive, and launch `NimCap.Screenshot.exe`. The .NET runtime is included; offline AI models must be downloaded or imported separately. Verify the archive against `SHA256SUMS.txt`.

Users migrating from SnapSharp v1.1.3 or earlier should download and extract the new version manually. NimCap v1.1.4 users can also use the in-app updater.
