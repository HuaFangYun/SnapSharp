## 使用指南的发布方式

《使用指南》是一篇只介绍软件本身的独立操作教程，包含首次配置、日常步骤和常见问题，不依赖关联文档、仓库相对链接或本机截图路径。可将全文复制到支持 Markdown 的博客编辑器发布；不支持 HTML 锚点的平台可以移除 `<a id="…"></a>` 行，不影响正文阅读。使用者无需获得其他文档才能完成基本操作。
