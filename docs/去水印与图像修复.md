# 去水印与图像修复

识别窗口左侧新增“去水印”。图片在本机处理，权重不随程序打包。

窗口打开后只显示图片，点击按钮才开始处理。顶部一行选择模型、设备及设置；图片下方一行提供模式、必要参数、去水印、撤销与输出。去水印和抠图始终为左侧原图、右侧结果，两侧缩放和平移同步。导航文字不自动折行，二维码和一维码按完整名称分行。

## 使用

1. 模型列表显示所有可选模型。选择未安装模型时，确认窗展示名称、用途、下载大小，并可选择官方源或中国源；下载并校验完成后自动配置路径、保存为对应功能的默认模型。取消或失败保留原配置。也可继续通过设置下载或导入模型。
2. 涂抹模式：左键涂抹水印，鼠标处的圆圈表示实际笔刷范围；滑块使用截图工具栏样式，可擦除误选、撤销和清空。
3. 选定区域模式：使用蚂蚁线框出检测范围，点击“去水印”一次完成范围内识别和图像补全；不显示笔刷及阈值。
4. 智能模式：点击“去水印”一次完成全图识别和补全；不显示笔刷及阈值。
5. 对比左右图片后复制、保存或贴图。需要修改自动蒙版时，可切换涂抹模式调整，再点击“去水印”。再次运行仍基于原图，便于比较模型。

预览图下方提供“撤销蒙版”“撤销修复”“显示蒙版”。撤销蒙版回退上一次选区编辑；撤销修复回到上一次修复结果，首次修复撤销后右侧恢复待处理状态，左侧原图和当前蒙版保留。取消显示蒙版可直接查看左侧原图，两侧无需切换。抠图提供相同的处理结果撤销。

处理结果撤销最多保留 4 次历史，估算图像内存不超过 128 MB；修改图片方向时清空旧结果历史；继续涂抹时保留上一处理结果，下一次成功处理后可撤销回上一结果。

预览区左键用于涂抹／框选，中键或空格加左键平移，滚轮缩放。
在左侧原图上涂抹，右侧只用于查看结果；处理中不能修改图像、蒙版、模型或处理方式。
旋转、翻转原图会清空旧蒙版和结果，防止坐标错位。

成功加载并验证 ONNX 输入输出后才更新配置；取消或失败保留旧配置。
三档均在软件内提供官方源与中国源；Moebius 的三个文件一起下载、逐个校验，全部验证成功才保存路径和默认模型。用户无需安装 Python、转换模型或定位文件。中国源使用 hf-mirror.com；镜像服务可能重定向回官方源，不代表独立托管保证。

LaMa 包含 Fourier 相关算子，不承诺全部计算都能在 GPU 上执行。

修复裁出蒙版周围的上下文，限制张量尺寸，再将结果合回原分辨率。
只替换原始蒙版内 RGB，保留原透明度和蒙版外像素。原图最多 1600 万像素。
蒙版撤销最多 8 步且合计不超过 64 MB。

## SLBR 自动识别

区域与智能模式使用 SLBR 输出的概率蒙版和已配置的阈值，一次操作自动交给所选模型补全图像；界面不再要求手动调阈值或先点击识别。
SLBR 已支持软件内自动下载：官方源使用原作者 Google Drive checkpoint，中国源使用固定版本的社区镜像，经 hf-mirror.com 下载。下载大小分别为 85,707,015 与 85,782,395 字节，确认窗口随来源更新大小和地址。
区域或智能模式缺少 SLBR 时留在当前页面，说明其识别用途；若修复模型也缺失，合并为一次确认。全部安装成功才保存路径和所选修复模型的默认值，取消或失败保留原配置。涂抹模式不需要 SLBR。
软件使用内嵌的固定安装映射读取已校验 checkpoint 的张量字节，自动生成并校验 ONNX，在隔离进程中验证输入输出。镜像的部分运行统计与官方不同，安装映射保留官方统计，因此两种来源得到同一份官方参数 ONNX。用户无需安装 Python、转换模型或寻找文件；运行时不执行 pickle。
最终 ONNX 大小为 86,773,294 字节，SHA256 为 `c151347105c2ecfdba1887223bc4b8732ce5d5b828ff2005d5086174c0faa0ec`。来源、校验值和上游条件见 `ThirdPartyLicenses/SLBR-MODEL-CARD.md`。

以下为可选的开发端导出流程，普通用户不需要执行。开发环境准备 PyTorch、ONNX、NumPy，取得官方源码和 CLWD checkpoint：

- 源码：https://github.com/bcmi/SLBR-Visible-Watermark-Removal
- 固定源码提交：`47c665f1855ab6624cd52b28cefa797a9c8b96f7`
- 官方 checkpoint 入口：上述 README 的 Pretrained Model。

```powershell
python scripts/export-slbr-onnx.py --source 路径/SLBR-Visible-Watermark-Removal --checkpoint 路径/model_best.pth.tar --output 路径/slbr.onnx
```

工具不下载或修改上游源码，不安装运行库；checkpoint 使用 `weights_only=True` 加载。
输入契约：`image` float32 `[1,3,256,256]` RGB [0,1]。
输出契约：`mask` float32 `[1,1,256,256]`，0–1 水印概率；另输出 `background` 便于核对。
应用导入时在子进程中验证输入输出，失败不改配置。
源码和权重的分发条款需要在提供托管下载前分别核实。

## 验证与限制

专项检查命令（模型目录包含 `migan.onnx`、`lama.onnx`）：

```powershell
.artifacts/watermark-build/NimCap.Screenshot.exe --watermark-self-test .artifacts/watermark-research/models .artifacts/watermark-checks
```

SLBR 自动安装专项检查（目录需包含官方和镜像 checkpoint，以及参考 `slbr.onnx`、`lama.onnx`）：

```powershell
.artifacts/slbr-auto-build/NimCap.Screenshot.exe --slbr-self-test .artifacts/watermark-research/models .artifacts/slbr-verified-checks
```

该检查通过本地 HTTP 测试处理器提供真实权重，验证两种来源的地址、校验、原生重建、相同目标哈希、真实 CPU 推理和跨来源缓存复用；同时检查缺模型合并确认、取消及部分安装失败时保留原设置、成功持久化路径与修复模型默认值。检查结果写入 `watermark-checks.txt`，不代表所有地区的网络连通性。

检查蒙版绘制、裁剪、撤销、模式切换、中英文布局、复制输出事件、可移植配置、
真实模型 CPU 推理、下载哈希／契约／缓存，以及蒙版外像素和透明度不变。
若模型目录含专用合成 `slbr-fixture.onnx`，还检查检测范围与阈值；这不代表真实 SLBR 质量通过。
如果目录含 `slbr.onnx`，还检查真实 SLBR 权重在子进程中的加载、区域与全图识别。
